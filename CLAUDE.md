# helixtone

Builds Line 6 Helix LT (`.hlx`) and POD Go (`.pgp`) presets from plain tone
specs. Personal project: the players and their gear are in `rig/rig.md`.

- To make or change a tone, use the `helix-tone` skill (`.claude/skills/helix-tone/`).
- `python -m helixtone --help` for the commands; no dependencies beyond Python 3.10+.
- `python -m unittest discover -s tests` runs the checks. The comparison
  against real presets needs `HELIXTONE_SOURCES` (see `tests/test_factory.py`);
  run it after any change to `helixtone/builder.py` or `tools/build_data.py`.
- File-format facts come from real files, never from memory. If a format
  question comes up, find a real preset that shows the answer and add it to
  the comparison test.
- `helixtone/data/` is generated by `tools/build_data.py`; do not edit it by hand.
- Measuring and tuning (`helixtone tune ...`) need numpy and a renderer. The
  Helix Native renderer works on Daniel's PC (needs pedalboard and pywin32).
  `.claude/skills/helix-tone/references/native-setup.md` says how it gets a
  preset into the plugin and what to do when it stops. After any change to
  `helixtone/render.py` or `helixtone/native_host.py`, run
  `python -m unittest tests.test_native`.
